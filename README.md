# Simula-o-de-Elei-o-Eletr-nica
API para simular uma eleição eletrônica: gerenciamento da eleição, cadastro de eleitores e candidatos, votação sigilosa e acompanhamento dos resultados.  Stack: Node.js, NestJS, TypeScript e PostgreSQL. O Front-End (Ionic/React) é um projeto separado e se comunica com o Back-End apenas pelo contrato da API, documentado com Swagger/OpenAPI.
